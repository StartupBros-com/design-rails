This repository is archived. It keeps the history and releases up to v0.13.0.
Releases from v0.13.1 on, issues and pull requests are in
[StartupBros-com/hov-stack](https://github.com/StartupBros-com/hov-stack). Its open issues moved there with the `plugin:design-rails` label.

## Install

From the [House of Vibe marketplace](https://github.com/StartupBros-com/hov-stack):

```
/plugin marketplace add StartupBros-com/hov-stack
/plugin install design-rails@hov
```

An existing install from the marketplace picks up the new home on its next
plugin update. There is nothing to reinstall.
